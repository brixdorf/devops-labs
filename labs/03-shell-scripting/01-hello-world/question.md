## Hello, World!

Your task is to write a simple shell script named `solution.sh` at `/home/user` that prints:

```
Hello, World!
```

This is your very first shell script, think of it like the first song in your playlist.

## Requirements

1. The script must be saved as `/home/user/solution.sh`.
2. The script must start with the correct shebang line.
3. It should output exactly `Hello, World!` with no extra whitespace or formatting.

## Notes

- The checker runs your script with `bash /home/user/solution.sh`.
- Mind the comma and the exclamation mark.

## Expected outcome

Running the script prints exactly `Hello, World!` and nothing else.
