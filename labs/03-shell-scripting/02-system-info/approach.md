1. `cd ~` and create the file with `touch system_info.sh`.
2. Make it executable with `chmod +x system_info.sh` and check with `ls -l`.
3. Open it with `nano` and add the shebang, three comment lines (`# Author: ...`, `# Version: ...`, `# Description: ...`) and an `echo` line.
4. Run it with `./system_info.sh`.
