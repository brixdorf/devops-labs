1. Open the terminal. It starts in your home directory. Run `pwd` and append its output to `answer.txt`.
2. Move into `task_1` with `cd task_1`, then append the command name `cd`.
3. List the directory with `ls`, then append `ls`.
4. Run `ls -a` (or `ls -la`) to show hidden entries. Append the name of the file that starts with a dot.
5. Check the result with `cat /home/user/answer.txt`. If you made a mistake, remove the file with `rm /home/user/answer.txt` and start again.
